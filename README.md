# ICKAB Modules

Repositorio oficial de módulos Odoo desarrollados por ICKAB.

## Objetivo

Centralizar, organizar y distribuir los módulos oficiales de ICKAB que hayan concluido su desarrollo, superado las pruebas correspondientes y sido autorizados para su publicación.

## Organización

Los módulos se clasifican por versión principal de Odoo:

- `17.0/` — Módulos compatibles con Odoo 17.
- `18.0/` — Módulos compatibles con Odoo 18.
- `19.0/` — Módulos compatibles con Odoo 19.

Cada módulo conserva su propio nombre técnico, versión y dependencias.

## Política de publicación

- Únicamente se incorporan módulos terminados y aprobados.
- Cada módulo mantiene un versionado independiente.
- Las publicaciones oficiales se realizan mediante GitHub Releases.
- Cada Release contiene el paquete ZIP correspondiente al módulo y versión.
- Las actualizaciones críticas se identifican y documentan.
- Las personalizaciones exclusivas de clientes no forman parte de la distribución general.
- Toda publicación requiere autorización de ICKAB.
